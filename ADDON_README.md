# Assessment Add-on Pack (v3)

What's new in v3:
- CI runs pytest **single-process** for reliable coverage.
- CI adds an **import preflight** for `app` and `models` with clear failure output.
- Added **edge-case tests** to help reach the 80–100 band.

## Install
1. Extract into repo root.
2. Commit & push to your fork.
3. Open the **Actions** tab to watch the pipeline.
